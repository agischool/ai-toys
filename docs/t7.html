02

Q 提问，K 匹配，V 提供被搬运的内容

想象你在一张有四条记录的表里找信息。Query（Q）描述这次查找的方向，Key（K）用于比较匹配程度，Value（V）才是最终被读取和混合的内容。Q 与 K 得到的分数决定“从哪里取多少”，输出则是这些 V 的加权和。

这只是方便理解的类比。神经网络中的 Q、K、V 通常是同一组输入乘上三套可学习矩阵后的数值向量，不一定能直接翻译成一句问题、一个标签和一段文字。一个向量可以同时承载很多特征。

本页用二维 K 和一维 V，让你能完整看见每一步。除正在编辑的 query 外，其他行的 Q 与对应 K 相同；切换编辑位置时，控件会显示该位置默认的 Q。这里没有训练 Wq、Wk、Wv。

缩放点积注意力
  1. 匹配sᵢⱼ = qᵢ·kⱼ / √dₖ
  2. 遮挡禁止位置的 score = −∞
  3. 归一化aᵢⱼ = exp(sᵢⱼ) / Σⱼ exp(sᵢⱼ)
  4. 混合oᵢ = Σⱼ aᵢⱼ vⱼ

softmax 按每一行独立计算。实现先减去该行最大分数再取指数，提高数值稳定性，不改变结果。

03

一次能在纸上完成的读取

分数相同，就平均读取

假设有两个可读位置，Q·K 的两个结果都是 0。exp(0)=1，因此权重为 [1/2, 1/2]。如果 V=[2,6]，输出就是 0.5×2 + 0.5×6 = 4。这个数不在原来的两条记录中，而是一次真实的混合。

在实验里选位置 2、保留因果掩码，再点“把当前 query 归零”。位置 3、4 不可读，因此权重恰好是 [0.5,0.5,0,0]，输出就是 4。这也对应原 Python 的等权手算例。

现在把 Q 改为 [0,1]。两个允许分数变成 [0,1/√2]，第二条的权重大约是 0.6698，输出约为 4.6790。分数更大通常会获得更多权重，但不会自动变成只选一个位置。

为什么除以 √dₖ？若向量分量的尺度合适且大致独立，点积的波动会随维度增长。缩放能缓和高维点积过大、softmax 过早饱和的问题；它不是一个能让任意输入都变稳定的保证。

04

因果掩码：只改变能读到哪里

下一字符预测时，位置 i 的计算不能偷看还没出现的字符。因果掩码把 i 右侧的分数设成 −∞，在 softmax 后形成严格的零权重。对角线保留，所以一个位置仍然能读取自己的输入。

这不会让计算真正回到过去，也不会储存历史。它只是限定当前计算图中的连接。训练时所有已知位置可以组成一个矩阵并行计算，只要每一行的可见范围符合规则。

选位置 2 并拖动位置 4 的 value：打开掩码时，位置 2 的输出不变。关掉后，它才可能改变。注意，调整 V 不会改变注意力权重，因为本实验的 Q/K 没有变化。

三个可检验的判断

  1. 位置 1 打开因果掩码，输出必为 V₁=2
  2. query 归零后，对所有允许位置均匀分配
  3. 任一行输出都在允许 V 的最小值和最大值之间

第三条来自非负、总和为 1 的加权和。完整网络还有输出投影和残差，不一定仍在原 V 的标量范围内。

05

权重告诉你路由，不能替代解释

机制边界

混合不是硬检索

分数差有限时，多个值通常会同时进入输出。高权重位置的 V 若本身不含有效信息，也不会自动产生正确答案。

解释边界

热图不是因果说明书

注意力权重只展示这一层的一次路由。还要考虑 V、输出投影、残差与其他层；不能仅凭深色格就断言模型“因为这个词才这样回答”。

实验边界

没有任务，就没有准确率

原 T7 验证前向运算、显式反向梯度和未来信息隔离，并没有训练一个语言模型。本页也没有测试集或理解评分。

全连接注意力需要保存位置之间的分数矩阵，标准实现的这部分随序列长度 T 呈 T² 增长。让远距离位置直接交换信息，带来了不同于 RNN 的计算与存储成本。下一章会把这项算子放进完整的 decoder block。

注意力不是一个神秘动作，而是一行分数、一行归一化权重和一次可核对的加权求和。
