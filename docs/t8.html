02
把注意力、残差和小网络接在一起
一层 decoder 不只是一张注意力热图。它先把字符变成向量，加上位置信息；再通过注意力，让位置之间交换信息；接着用逐位置的前馈网络变换特征。两条分支都把变化量加回主路径，因此会用到 T5 的残差连接。
这里使用 Pre-LN 排列：先 LayerNorm，再进入分支，最后残差相加。LayerNorm 在同一个位置的特征维度上计算均值和方差，不把各个位置混在一起。本页缩放参数固定为 1、偏置为 0，方差加 ε=10⁻⁵ 后再开平方作分母。
注意力分支是唯一让不同位置互相交换内容的地方。FFN 的 4→6→4 矩阵对每个位置独立应用，并在中间加入 ReLU。所有位置共享同一套矩阵，但因为输入不同，输出也不同。
完整前向路径
  1. 表示X = token embedding + position
  2. 读入A = Attention(LN₁(X))
  3. 相加U = X + A
  4. 变换F = ReLU(LN₂(U)W₁+b₁)W₂+b₂
  5. 输出H = U + F；logits = H·Whead
最后 softmax 把 logits 转成词表上的分布。固定权重也会给出一组数值；有分布并不等于预测已经可靠。

手算入口，再逐项检查整个位置
默认序列的第一个 A
A 的 embedding 是 [1, 0, 0.2, −0.3]，位置 1 的向量为全零，因此 X 不变。四维均值是 0.225，方差是 0.231875。除以 √(0.231875+10⁻⁵)，得到 LN₁(X)≈[1.609405, −0.467247, −0.051916, −1.090242]。
位置 1 只能读取自己，所以注意力权重严格为 [1,0,0,0,0,0]。这仍不意味着分支输出等于 X：输入先经过 LN、Wv 和 Wo。当前分支的实际输出为 [0.210261, 0.060223, −0.053474, −0.011422]。
U = X + A ≈ [1.210261, 0.060223, 0.146526, −0.311422]
随后第二次 LN、FFN 与残差得到 H≈[1.200879, 0.122530, 0.194296, −0.179817]。把“跟踪的位置”切到 1，可在表里核对每个中间结果。表格显示六位小数，内部使用未舍入值。

04
用干预检验：未来有没有偷偷进来？
选中前面的某个位置，点击“轮换最后一个字符”。因为整个 block 的注意力采用下三角掩码，前面所有位置的 H 都应保持不变。页面会实际重算两次，并报告前缀向量的最大绝对差，而不是直接打印一个预设的 0。
这个检查比看一眼热图更扎实：未来除了不能穿过注意力，也不能通过跨位置归一化、错误的索引或其他旁路泄漏。本页的 LayerNorm 和 FFN 都只在当前行计算，因此保持因果性。长度为 1 时没有可比较的前缀，页面会说明这一点。
关掉注意力分支，再修改序列：每个位置仍会经过 embedding、位置向量、FFN 和输出头，但再也读不到其他位置的内容。这是结构消融，并不等价于重新训练一个无注意力模型。
试着解释这三个现象
  1. 为什么位置 1 的注意力只有一个可读格，却仍可能改写特征？
  2. 相同字符在位置 1 和位置 4，为什么通常输出不同？
  3. 取消注意力后，为什么网络仍然会给出一组概率？
展开核对思路
值投影和输出投影还在起作用；位置向量以及可读前缀不同；其余网络和 softmax 没有被删除。能产出数字与学会任务是两回事。
05
原 Python 训练什么？又没证明什么？
原 T8 是一层、单头、Pre-LN 的 decoder，特征宽度 16，FFN 宽度 32，使用可学习的位置向量。词表为 <abcde|>，完整序列形如 <abcd|abcd>。五个字母组成长度为 4 的片段，共 625 种可能；脚本先按完整唯一序列划分训练与留出测试数据，再形成下一字符输入和目标。
训练时使用 teacher forcing：每个位置读到真实的此前字符，然后预测下一个字符。复制区逐 token 准确率只衡量这些位置的预测；自由生成则把模型自己的预测继续喂回去，任何早期错误都可能改变后续输入。复制 token 准确率与整串自由生成 exact match 不是同一指标。
源代码显式写出所有反向传播，包括 LayerNorm、注意力、FFN、嵌入表与输出头，并对梯度、参数存取和因果性进行检查。页面的 D4 固定参数模型没有装载它的训练权重，也没有重放训练曲线，所以不混用任何训练结果。
任务边界
复制不是开放语言理解
小字母表和短序列提供可控制的验证环境，不能据此声称有真实语言知识、事实可靠性或推理能力。
位置边界
固定窗口有明确上限
本页仅有六行位置向量，所以拒绝更长输入。原 Python 也有有限的位置表；更长输入不能未经验证地直接套用。
规模边界
一层是结构切片
现代模型还有更多层、不同位置编码和训练配方。这个实验帮助检查基本路径，不是 ChatGPT 的缩小等价物。
Transformer 可以一层层拆成普通的数值运算。能力来自这些运算、参数、数据与训练过程的共同作用。
