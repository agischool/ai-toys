## 文件用途

| 文件 | 用途 |
| --- | --- |
| `index.html` | 浏览本期内容、预览图片并复制文案 |
| `发布文案.md` | 「标题」和「摘要」分别放在独立文本块中，可分别复制 |
| `公众号_排版.html` | 已排版的公众号正文，保留内联样式、内嵌配图和「选中正文」按钮 |
| `正文.md` | 完整 Markdown 正文，用于编辑和保存源文 |
| `互动版.html`（第 01—14 篇） | 全屏逐拍阅读，含目录缩略图、自动播放、翻面练习卡和全文模式；可本地双击打开 |
| `分镜.json`（第 01—14 篇） | 将正文单元依次分配给场景、镜头和字幕；修改正文后须重新构建 |
| `00_封面图_横版2.35.png` | 横版封面 |
| `00_封面图_方形1x1.png` | 方形分享封面 |
| 其他 PNG 文件 | 正文配图，与 Markdown 中的相对路径对应 |

## 发布步骤

1. 打开本篇 `发布文案.md` 的 Markdown 预览。
2. 复制「标题」下的文本块，粘贴到公众号标题栏。
3. 复制「摘要」下的文本块，粘贴到摘要栏。
4. 用浏览器打开本篇 `公众号_排版.html`，点击页面顶部的「选中正文」。
5. 按 `⌘C`（macOS）或 `Ctrl+C`（Windows）复制，粘贴到公众号正文编辑区。
6. 检查图片是否上传成功；缺失时手动插入同文件夹中的对应 PNG。
7. 设置封面，检查裁切，并按实际制作方式和平台规则填写 AI 标识。
8. 发送手机预览，核对字号、段落、图片和引用编号。

第 [01 篇](01_AI到底在做什么%20从认猫开始/index.html)、第 [02 篇](02_只见过红色积木%20就认不出蓝色积木了吗/index.html)均可从单篇页面打开互动版。第 02 篇的红蓝积木为手写规则算例，三张翻面卡用于比较换色与混合测试的成绩。发布到 GitHub Pages 后，可将互动版的公开地址放入公众号「阅读原文」；公众号正文仍使用 `公众号_排版.html`。

第 [03 篇](03_一张图怎样变成一串数字/index.html)互动版用九格图案演示逐行编码、还原与中心改值，三张翻面卡可核对两条对角线和空心十字。灰度与 RGB 色样使用对应的实际数值；平均缩小算例展示两种排列怎样得到同一个灰格。

第 [04 篇](04_电脑做错后究竟改了什么/index.html)互动版固定输入与目标，用同一个参数 b 比较预测和总绝对误差；三张翻面卡核对 b＝3 时的结果。后半篇区分手动搜索、自动更新和训练后的使用，并保留改目标的反例与零损失的适用边界。

第 [05 篇](05_小窗口怎样找出图中的线索/index.html)互动版逐格计算响应，让同一个模板依次检查三个窗口，再比较竖线平移后的特征图。三张翻面卡用负权重模板核对竖线、全黑图块的分数，并区分手工修改与训练；步长与边缘算例保留适用边界。

第 [06 篇](06_神经网络越深为什么不一定更好/index.html)互动版把原值与 F 分支分开布线，比较加 1、保持原样和减 1 的修正；三张翻面卡用于核对修正值与分支是否保留。选读部分演示两路变化相加、反向传递和抵消为零的算例，同时保留形状匹配与训练效果的边界。

第 [07 篇](07_一句话的线索怎样传到最后/index.html)互动版比较同一故事的两种便签规则，再用数值状态、共享参数和简化门控乘加演示保留与写入。三张翻面卡检查换蓝伞后的记录；连续衰减示意保留“数值不等于记住多少故事”的边界。

第 [08 篇](08_一次接一片文字怎样生成一段话/index.html)互动版用两条手写路线比较贪心与采样，十张等机会卡片展示 0.6 / 0.4 的含义。完整循环保留继续与停止分支，三张翻面卡核对换开头后玩具是否使用了更早线索；词元、界面显示和事实核查分别说明。

第 [09 篇](09_这句话里的它到底指谁/index.html)互动版对照「太大」与「太小」的通常指向，逐步计算相同信息在不同权重下的组合。三张翻面卡核对等权结果、结果范围与指代理解的边界；查询、键、值、多头合并和可用上下文分别作图，保留权重不等于答案把握、权重图不等于完整解释的限制。

第 [10 篇](10_把语言模型的零件连成Transformer/index.html)互动版从两片输入出发，连接嵌入、位置表示、块内分工、因果遮罩与两轮生成。三张翻面卡核对输入行、可读前缀与下一片目标的一格偏移；完整保留残差支路、原文采用的归一化顺序、生成循环与事实核查边界。编号、向量和候选概率均明确标为人为示意。

第 [11 篇](11_给AI一本笔记本会发生什么/index.html)互动版逐格写入红、蓝、黄，读取第 2 格后覆盖为绿，再比较两次读取。三张翻面卡核对先读 3、再读 2 与恢复旧蓝的请求；加权读取明确展示 2 × 0.75 ＋ 10 × 0.25 ＝ 4，区分组合与随机取一格。参数、内部状态、外部存储，以及 RAG、联网搜索和产品保存规则分别说明。

第 [12 篇](12_大模型越大就一定越好吗/index.html)互动版按成本、时限与答对题数筛选三个虚构方案，比较条件改变后的选择；三张翻面卡核对同时满足三项要求时的无解结果。训练流水线仅示意前向安排，论文比较另保留训练预算、MMLU 的 5 示例设置与 57 项任务条件。

第 [13 篇](13_更短的规则能讲清更多事情吗/index.html)互动版逐字符核算直接模式、重复规则与例外的长度，展开后核对原串，再比较同一原串的候选写法。三张翻面卡检查 R3AB6C 的解码、总长与节省量；保留专用字典成本、描述长度与运行时间的区别，以及有限候选比较的边界。

第 [14 篇](14_认出物体就理解关系了吗/index.html)互动版交换蓝方与绿三角，比较同一对象清单为何得到不同的左侧计数；横竖屏都保留图上的左右顺序。关系箭头包含非相邻对象，示意坐标与手工比较另行说明；三张翻面卡检查左右顺序为什么不能确定厘米距离，并指出缺少的信息。第 15—24 篇继续制作。

互动版在仓库根目录通过 `npm run build` 生成，`npm test` 检查正文完整覆盖、生成物一致性、外链、本地资源及 512 KiB 的 HTML 体积上限。第 02 篇浏览器验收使用 `npm run test:stage:browser -- 02`，逐拍截图使用 `npm run test:stage:shots -- 02 --out=/tmp/stage02`；编号省略时默认检查第 01 篇。需本机 Playwright 与 Chrome，并通过 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH` 指定安装位置。滚轮、方向键或手机上下滑动每次切换一拍；系统开启「减少动态效果」时默认进入全文模式。

标题、摘要可通过预览器的代码块复制功能分别复制。长文章发布时优先使用排版 HTML，Markdown 保留为可编辑正文。修改 `正文.md` 后，在仓库根目录运行 `npm run build` 自动更新排版 HTML，保留文末资料来源与引用编号；直接修改生成的 HTML 会在下次构建时被覆盖。

## 续篇实验与素材

17—20 期的 [校园助手实验](../Python实现/source/campus_agent_lab/README.md) 只用标准库、构造资料与预设规则；21—23 期的 [机制实验](../Python实现/source/continuation_mechanisms/README.md) 使用 NumPy 核对损失、缓存和路由。没有模型服务调用，不需要购买 API 额度或 GPU。运行条件和保存结果见各自说明。

17—24 期每篇的 `素材源/` 保存图解与封面的可编辑 HTML/SVG，PNG 由浏览器导出，延续前 16 期的米白、青绿、珊瑚与粗线机制图。小机器人由 imagegen 参考既有角色提取为透明素材，封面排版和机制图由代码绘制；发布时按实际制作方式填写平台 AI 标识。正文与图解的事实、数值及输出记录需一起核对。
