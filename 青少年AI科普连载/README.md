## 文件用途

| 文件 | 用途 |
| --- | --- |
| `index.html` | 浏览本期内容、预览图片并复制文案 |
| `发布文案.md` | 「标题」和「摘要」分别放在独立文本块中，可分别复制 |
| `公众号_排版.html` | 已排版的公众号正文，保留内联样式、内嵌配图和「选中正文」按钮 |
| `正文.md` | 完整 Markdown 正文，用于编辑和保存源文 |
| `00_封面图_横版2.35.png` | 横版封面 |
| `00_封面图_方形1x1.png` | 方形分享封面 |
| 其他 PNG 文件 | 正文配图，与 Markdown 中的相对路径对应 |

## 发布步骤

1. 打开本篇 `发布文案.md` 的 Markdown 预览。
2. 复制「标题」下的文本块，粘贴到公众号标题栏。
3. 复制「摘要」下的文本块，粘贴到摘要栏。
4. 用浏览器打开本篇 `公众号_排版.html`，点击页面顶部的「选中正文」。
5. 按 `⌘C`（macOS）或 `Ctrl+C`（Windows）复制，粘贴到公众号正文编辑区。
6. 检查图片是否上传成功；缺失时手动插入同文件夹中的对应 PNG。
7. 设置封面，检查裁切，并按实际制作方式和平台规则填写 AI 标识。
8. 发送手机预览，核对字号、段落、图片和引用编号。

标题、摘要可通过预览器的代码块复制功能分别复制。长文章发布时优先使用排版 HTML，Markdown 保留为可编辑正文。修改 `正文.md` 后，在仓库根目录运行 `npm run build` 自动更新排版 HTML，保留文末资料来源与引用编号；直接修改生成的 HTML 会在下次构建时被覆盖。

## 续篇实验与素材

17—20 期的 [校园助手实验](../Python实现/source/campus_agent_lab/README.md) 只用标准库、构造资料与预设规则；21—23 期的 [机制实验](../Python实现/source/continuation_mechanisms/README.md) 使用 NumPy 核对损失、缓存和路由。没有模型服务调用，不需要购买 API 额度或 GPU。运行条件和保存结果见各自说明。

17—24 期每篇的 `素材源/` 保存图解与封面的可编辑 HTML/SVG，PNG 由浏览器导出，延续前 16 期的米白、青绿、珊瑚与粗线机制图。小机器人由 imagegen 参考既有角色提取为透明素材，封面排版和机制图由代码绘制；发布时按实际制作方式填写平台 AI 标识。正文与图解的事实、数值及输出记录需一起核对。
