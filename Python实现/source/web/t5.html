02

残差：先保留，再修正

你画好了一只猫，请朋友修改。普通模块像让朋友交来一张全新的画；残差模块则保留你的原稿，再把朋友的修改叠上去。网络里的“原稿”是输入 h，“修改”是分支 F(h)。

普通模块输出 F(h)；残差模块输出 h + F(h)。如果分支输出为 0，残差模块就把输入原样传过去。它不需要先努力学出“复制输入”这件事。

相加要求形状相同。本章的标量相加没有困难，原 Python 也让每块输入和输出同为八维。真正改变维度的网络需要额外处理，本章没有偷偷加入投影捷径。

一个加号，两条路

前向相加，反向也相加

  1. 普通y = F(x)
    dy/dx = F′(x)
  2. 残差y = x + F(x)
    dy/dx = 1 + F′(x)
  3. 收到 g普通传回 g × F′(x)
    残差传回 g + g × F′(x)

这个额外的 1 来自 x 对自身的导数；不是额外训练出来的参数。

手算：x = 2，F(x) = 0.5x

普通：y = 0.5 × 2 = 1残差：y = 2 + 0.5 × 2 = 3

输入增加一个小量 ε，普通输出约增加 0.5ε，残差输出约增加 1.5ε，所以导数分别是 0.5 和 1.5。如果收到上游梯度 g = 2，就分别传回 1 和 3。

串联三块线性模块，普通导数变成 0.5³ = 0.125；残差变成 1.5³ = 3.375。有直达路既可能减轻衰减，也可能带来放大。点击“6 块：观察衰减”，再把 a 从 0.2 调到 1.5，看看这个区别。

03

把每一站连起来：链式法则

你轻轻改变第一站的输入，变化先经过第一站，再经过第二站……最后到达输出。每一站对小变化的放大倍率就是局部导数；全部倍率相乘，就是最终敏感度。

在线性模式中，每站普通倍率都是 a，残差倍率都是 1+a。N 块串联后，dy/dx 分别为 aᴺ 和 (1+a)ᴺ。本页表格没有省略任何一站。

非线性模式改为 F(h) = a tanh(h)，导数为 a[1−tanh²(h)]。当 |h| 很大时，tanh 逐渐饱和，分支导数会变小。两种网络的 h 不一样，所以即使用相同 a，局部倍率也会不同。

读图不要读过头

这不是训练曲线

我们给两种网络的输出端都放一个“1”，比较它们如何把这个敏感度传回输入。没有目标标签、损失函数或优化器，也没有声称哪一个学得更快。

纵轴使用对数刻度，才能同时看见 1 和 0.000064。等距离表示相同倍数变化；0 无法取对数，所以单独标在“精确 0”一行。绝对值相同但符号相反的点会重合，符号请查表。

04

一条捷径，不是万能保险

抵消

“加 1”仍然可以变成 0

线性 a = −1 时，残差的一站导数就是 1 + (−1) = 0。直达路和分支恰好抵消。因此不能说“残差保证梯度永远不消失”。

放大

梯度大，也可能麻烦

a 为正、模块较多时，(1+a)ᴺ 可能迅速增长。梯度并非越大越好；实际训练还与初始化、学习率、归一化和目标有关。

任务

修原稿，不一定适合所有题

原 Python 的目标特意含有 0.6x，带有类似恒等映射的成分。它适合观察“学习修正”，却不能用来宣布残差结构在所有任务上都赢。

残差连接提供了一条恒等路径。它改变计算与优化的条件，但不会替代数据、实验和判断。

05

三个小挑战

1 · 一条完全畅通的路

选线性分支，把 a 调到 0，再把模块数调到 12。猜两种网络的输出与 dy/dx。

核对答案

残差输出始终为 x，导数为 1；普通输出为 0，导数为 0。最后的输出边界对自身的导数仍是 1。

2 · 什么都没消失的负数

普通网络取 a = −1。试着切换奇数、偶数模块，观察 dy/dx 的正负号与绝对值。

核对答案

导数是 (−1)ᴺ，符号交替、绝对值始终为 1。负导数表示变化方向相反，不表示梯度消失。

3 · 输入也会改变倍率

设 a = 0.5、1 个模块，先用线性再用 tanh 分支。让 x 从 0 走到 2，比较导数。

核对答案

线性导数不随 x 变；tanh 分支导数从 0.5 降到约 0.0353，残差局部导数则从 1.5 降到约 1.0353。

06

原版复现：公平配对，也保留局限

网页用一个标量和一个系数隔离加法捷径。原 Python 是两种各有 432 个参数的八维网络，均为 3 个模块，每块分支是 tanh(hW₁+b₁)W₂+b₂；残差版额外加 h。没有卷积、归一化、额外分类头或最后一层激活。

从含 requirements.txt 的项目目录运行。依赖为 NumPy 2.3.5、Matplotlib 3.10.8 与标准库，全程 float64、手写反向传播。

为什么这个比较有价值，也为什么还不够
  • 输入各维从 [−1.5, 1.5] 均匀抽样；目标是 0.6x + 0.4 tanh(xA)。A 是固定随机 8 × 8 教师矩阵；数据由 seed+1000 生成。
  • 分支矩阵以标准差 0.7/√8 的正态分布初始化，偏置为零。同样初始参数不代表同样初始函数，因为残差相加会改变后续输入。
  • MSE 对所有样本和八个输出维度一起取平均；输出梯度是 2(预测−目标)/(N×8)。原版图记录的是损失梯度范数，两种模型的输出误差不同，不能把它当作本页“相同输出敏感度 1”的严格对照。
  • 原版保留三次配对运行的全部结果和均值、总体标准差。三颗种子的标准差是描述性统计，不是置信区间，更不是跨任务普遍优势的证明。
  • metrics.json 保存每步损失、参数 / 输入梯度范数、起止边界梯度。comparison.png 和 test_seeds.png 展示全部运行；六个带种子与模式的 .npz 分别保存模型。
  • parameters.npz 与 parameters_plain.npz 是第一颗种子的两种模型。load_model 同时恢复参数与 residual 模式，再送入 forward。
  • 中心差分检查两种网络的输入及所有参数；把全部 W₂、b₂ 置零时，残差前向与反向都应原样通过；保存再读取后预测也应一致。
  • 本页没有随机训练和外部依赖，所有操作在浏览器本地执行。刷新回到默认例子，输入不会上传。
