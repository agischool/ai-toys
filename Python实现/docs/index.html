02

“学习”，其实是改两个数

一条直线可以写成 ŷ = wx + b。w 管倾斜，b 管上下。机器先拿这两个数做预测，再比较预测和观测之间的差距。

把每个差距平方，再取平均，就是均方误差（MSE）。平方让正负误差不会互相抵消，也让偏得远的点付出更大代价。

只有四步
  1. 预测ŷ = wx + b
  2. 算误差e = ŷ − y
  3. 找方向dw = 平均(2ex)，db = 平均(2e)
  4. 改参数w ← w − η·dw，b ← b − η·db

η 是学习率。梯度告诉你局部上升方向，减去它，通常就能往误差较小的方向走。

把第一步算在纸上

只看一个点：x = 2，目标 y = 5。起点 w = 1、b = 0，预测是 2，平方误差是 9。

dw = 2 × (2 − 5) × 2 = −12db = 2 × (2 − 5) = −6

学习率取 0.1，更新后 w = 2.2、b = 0.6，预测恰好变成 5。一步到位只是这组数字的巧合。完整实验里，梯度要对所有训练点取平均，通常要反复更新。

03

误差变小，不等于无所不能

步长的边界

走得快，也会走过头

学习率为 0，参数不动；太小，进展缓慢；太大，可能来回越走越远。可以把学习率调到 1.10，再从头看一次。

模型的边界

直线学不出所有弯曲

这里的生成规律是 1.7x + 0.4 + 0.18x²，再加上噪声。即使噪声为 0，直线仍有表达限制。训练误差不为 0，不一定是训练失败。

数据的边界

见过附近，不代表懂得远方

默认模型在 x = 3 时预测约 5.559；生成规律的无噪声值是 7.12。训练只见过 [−1, 1]，范围内拟合好，不能保证范围外可靠。

这条直线没有神秘的“领悟”时刻。预测、误差、导数、更新，都是能逐步检查的数字运算。

实验约定与复现说明
  • 训练与测试使用独立随机流。测试点不参与梯度更新。
  • 改变噪声会同时改变训练与测试的观测噪声，因此不同噪声结果不是同一测试集上的严格因果比较。
  • 改变样本量会改变训练数据，单次结果不保证样本越多误差就越小。
  • 网页中的三组种子和五档样本量来自固定 NumPy 数据夹具。下载包可重新生成并验证它们。
  • 误差过大或计算不再有限时，实验会提前停止；图表使用固定数据视窗，过大的直线会被裁切，但数值和警告仍会显示。
  • 所有计算在浏览器本地进行，无需登录实验账户，也不会上传输入或采集分析数据。
