# 公众号发布材料

[打开网页目录](index.html)：按期浏览，预览图片并复制发布文案。每期文件夹中的 `index.html` 可直接双击打开。

两套系列各含 16 个编号文件夹。标题和发布文案使用 Markdown；长文章同时保留可编辑 Markdown 与公众号排版 HTML，图片保留 PNG。

| 系列 | 形式 | 使用说明 |
| --- | --- | --- |
| 少年 AI 观察室 | 5 张正文图、标题与描述 | [查看 README](少年AI观察室/README.md) |
| 青少年 AI 科普连载 | 长文章、标题、摘要与配图 | [查看 README](青少年AI科普连载/README.md) |

## 复制方式

打开每期的 `发布文案.md`，分别复制「标题」和「正文」或「摘要」下面的文本块。支持代码块复制的 Markdown 预览器可直接点击复制按钮；复制结果不包含标题标签或 Markdown 围栏。

| 内容 | 粘贴位置 |
| --- | --- |
| 标题文本块 | 公众号标题栏 |
| 少年 AI 观察室的正文文本块 | 图片贴图的描述栏 |
| 青少年 AI 科普连载的摘要文本块 | 长文章的摘要栏 |
| 青少年 AI 科普连载的 `公众号_排版.html` | 浏览器打开，点击「选中正文」后复制到正文编辑区 |

长文章发布时使用 `公众号_排版.html`，保留原有内联样式和内嵌配图；`正文.md` 用于改稿。粘贴后确认图片上传成功，必要时手动插入同文件夹内的 PNG。

发布前核对本期标题、文案与图片，按实际制作方式和平台规则填写 AI 标识，并发送手机预览。文件整理不代表已上传或已发布。
