# 少年 AI 观察室

[打开网页目录](index.html)：按期浏览，预览图片并复制发布文案。每期文件夹中的 `index.html` 可直接双击打开。

[返回总说明](../README.md)

每期保留 8 个文件：发布文案、5 张正文图和 2 张封面。

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `发布文案.md` | 「标题」和「正文」分别放在独立文本块中，可分别复制 |
| `发布图片/01.png` 至 `05.png` | 按编号顺序上传的正文图片 |
| `公众号主封面_21x9.png` | 横版封面 |
| `公众号分享封面_1x1.png` | 方形分享封面 |

## 发布步骤

1. 打开本期 `发布文案.md` 的 Markdown 预览。
2. 复制「标题」下的文本块，粘贴到公众号标题栏。
3. 复制「正文」下的文本块，粘贴到图片贴图的描述栏。
4. 按顺序上传 `发布图片/01.png` 至 `05.png`。
5. 根据当前编辑页的选项设置封面，检查裁切。
6. 按实际制作方式和平台规则填写 AI 标识，并发送手机预览。

支持代码块复制的预览器可点击文本块的复制按钮。保留正文末尾「说明：」中的解释边界和 AI 插画声明。

## 文案格式

正文按以下顺序组织，各部分之间空一行：栏目名与两位期号、导语、核心结论、「想一想：」互动问题、「说明：」。说明段先写本期算例的范围与限制，再另起一行写配图声明。

栏目行使用 `少年 AI 观察室 · 第 01 期` 的格式，期号随文件夹编号变化。配图声明统一为：

```text
首图为 AI 辅助生成的概念插画，第 2—5 张为按规则绘制的图解。
```

标题和正文仍分别置于独立文本块中，便于直接复制。正文文本块粘贴到公众号图片贴图的描述栏。
