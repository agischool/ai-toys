# T1：让一条直线学会调参数

这个样章把线性回归的预测、均方误差、解析梯度和全批量梯度下降拆成可检查的数字运算。

## 运行原版 T1

建议 Python 3.11 或更新版本。先建立虚拟环境，在本目录运行：

```sh
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell 对应命令：.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m toys.t01_linear
```

结果写入 `outputs/t01/`：拟合与误差图、范围外预测图、参数文件和 `metrics.json`。
默认种子 42，训练点 32 个、测试点 16 个，输入均在 [−1,1]。
生成函数为 `1.7*x + 0.4 + 0.18*x*x`，加标准差 0.08 的高斯噪声。
学习率 0.1，更新 200 次。

| 指标 | 默认实测值 |
|---|---:|
| w | 1.697269770221289 |
| b | 0.4672040346857402 |
| 初始训练 MSE | 1.5233951954207863 |
| 最终训练 MSE | 0.006263976715061485 |
| 最终测试 MSE | 0.007890755977448243 |

`toys/t01_linear.py` 与原 T1 保持一致；浏览器不运行 Python，它用 JavaScript 实现相同的计算。

## 样章 v1 扩展

`sample_v1.py` 仅为互动样章扩展数据选项：种子 7/42/2026，训练样本量 8/16/32/64/128，测试点固定 16 个。

```sh
python sample_v1.py --seed 42 --samples 32 --noise 0.08 --lr 0.1
python sample_v1.py --fixtures regenerated-fixtures.json
python -m unittest discover -s tests -v
```

`fixtures.json` 由 NumPy 生成，含输入和标准正态噪声，以及 270 组对照结果。网页读取这些固定数据，按所选噪声缩放，独立计算梯度与更新；没有模拟 NumPy 的随机数生成器。

默认扩展数据与原版数组逐元素相同。网页多显示第 200 次更新之后的误差，曲线含第 0 至第 200 步；原版 history 记录每次更新前的误差，共 200 项。最终参数一致。

扩展与网页在 MSE 超过 1e8 或结果不再有限时提前停止，最多 200 次更新。原版训练函数保留原有行为。

## 解释结果时要保留的边界

- 测试数据独立生成，不用于梯度计算
- 噪声改变时，训练与测试的观测条件一起改变，不是固定测试集的因果比较
- 样本量改变时，训练数据也改变，单次结果不保证样本越多误差越小
- 生成规律含轻微二次项，因此无噪声时直线也不能完全拟合
- x=3 在训练区间之外，不能把范围内测试误差当成外推可靠性证明
