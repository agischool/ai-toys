02

为什么读一串东西，需要“状态”？

如果一台机器每次只看眼前的字符，那么读到最后的问号时，开头的 A 或 B 早已不在输入里。RNN 的办法是留下一份隐状态：把旧状态和新输入混合，再交给下一个时间步。它是一个受容量约束的摘要，而不是完整的历史副本。

这里把多维向量缩成一个数，输入到状态的系数固定为 1、偏置固定为 0。循环权重 w 决定上一步贡献多少；tanh 把状态压到 −1 与 1 之间。每个时间步使用同一个 w，这叫参数共享，不是每读一个字符就新增一套参数。

沿时间展开，看起来有很多小单元；把它折回去，仍是同一个单元被重复调用。计算必须依序进行，因为第 t 步依赖第 t−1 步。

前向递推
  1. 开始h₀ = 0
  2. 混合zₜ = xₜ + w·hₜ₋₁
  3. 压缩hₜ = tanh(zₜ)
  4. 传递把 hₜ 交给下一步

完整 RNN 会把 x 和 h 换成向量，并用矩阵 Wxh、Whh 变换；另一个输出头把状态转成类别或下一字符的 logits。

→
x₂ + w·h₁ → tanh
h₂
→
x₃ + w·h₂ → tanh

→ …
03

手算两步，也把梯度的路找出来

默认的开头：x₁=1、x₂=0、w=0.5

第一步 h₁=tanh(1)=0.761594。第二步把它乘以 0.5，得到 z₂=0.380797，再取 tanh，得到 h₂≈0.363399。你可以点击两次“递推一步”，直接核对这两个值。

∂h₁/∂x₁ = 1 − h₁² ≈ 0.419974∂h₂/∂x₁ = (1 − h₂²) × 0.5 × 0.419974 ≈ 0.182256

tanh 的导数是 1−h²。沿着时间往回传一个微小变化，每多跨一步，就多乘一个 w·(1−h²)。网页展示的是最终状态对第一份输入的导数，不是损失梯度、训练速度或“记住的概率”。

训练时，输出先产生损失。反向传播穿过输出头，再沿着展开的时间链倒着走，这就是 BPTT（时间反向传播）。同一个参数在多个时间步被使用，因此它的梯度要累加来自所有使用位置的贡献。

当许多因子都小于 1，长程信号会变弱；在更大的矩阵模型里，某些方向也可能不断放大。这分别与梯度消失、梯度爆炸有关。tanh 状态有界，并不保证所有参数梯度都稳定。

本页的可核对链式法则

∂hₜ/∂x₁ = (1−h₁²) × ∏ᵢ₌₂ᵗ [w·(1−hᵢ²)]

把 x₁ 微增 ε，再微减 ε，最终状态之差除以 2ε，可以数值检查这个导数。下载 Python 还会逐参数检查完整 BPTT。

04

三个实验，让“记忆”露出边界

实验 A

w=0：过去立刻断开

把循环权重设为 0，干扰设为 0。第一步后，后续状态全部回到 0，首输入的敏感度也变成 0。不是机器忘得慢，而是计算图里已经没有传递路径。

实验 B

拉长等待，信号逐步缩小

恢复默认，把后续步数拉到 24，再算到最后。w=0.5 让链条不断乘上小于 0.5 的因子。非零不代表可靠可读；有限精度与噪声都会影响小信号。

实验 C

大 w 不等于更好的记忆

把 w 提到 1.5。状态可能维持很大的正负值，但 tanh 饱和处的导数小，细微变化仍可能难以传播。再加入干扰，看看状态与首输入敏感度是不是同一回事。

先预测，再操作

  1. 默认无干扰时，把 A 换成 B，整条状态曲线应如何变化？
  2. 状态接近 ±1 时，为什么导数反而可能更小？
  3. 如果从未训练任何参数，能把曲线变化叫作“模型学会了”吗？
展开核对思路

tanh 是奇函数，无干扰时 A/B 曲线关于 0 对称；导数 1−h² 在饱和区接近 0；滑块是人手设定参数，不能作为学会任务的证据。

05

从这一个数，到原始 RNN 实验

原 T6 的延迟回忆任务使用字符表 ABxy?。一串输入以 A 或 B 开头，中间夹入独立的 x/y 干扰，最后以 ? 结束；完整长度为 8–16，目标是在末尾判断最初的字母。训练集与验证集按完整且唯一的字符串划分，不能把同一字符串的不同切片分散到两边制造泄漏。

模型有 16 维 tanh 隐状态，显式实现 Wxh、Whh、bh、Why、by 的反向传播，使用 Adam 和全局梯度范数裁剪。裁剪能抑制过大更新，却不能恢复已经衰减掉的远程信息。原脚本还检查翻转首字符、删除首字符后的表现，用干预辨别模型是否依赖目标信息。

同一个文件另有独立的下一字符建模任务，使用 ABxy01> 字符表，并在每个真实时间步计算交叉熵。它与最后才输出答案的延迟回忆不能混成同一个准确率。这里称留出部分为“验证集”，不把它升级成额外、未接触的独立测试集。

RNN 的记忆是一条可微分的状态链。它能带来历史依赖，也带来了必须跨越许多步的学习路径。
