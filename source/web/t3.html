02

先把难题换一种表示，再做决定

想象两个开关：一样就关灯，不同就开灯。这叫异或，XOR。我们把每个开关写成 −1 或 +1，于是四种组合落在正方形的四个角。要亮的两点在一条对角线上，不亮的两点在另一条对角线上。

试着在纸上只画一条直线，能把亮与不亮分在两边吗？做不到。T2 的逻辑回归也有同样的表达限制。这不是“再学久一点”就能解决的问题。

多层感知机先让四个小单元各自读两个输入，得到四个中间数字 h₁ 到 h₄；最后一个单元组合这些中间结果。隐藏层好比四副小眼镜，每副关注不同的组合。它们的权重通过误差调整，不需要我们替每个单元命名。

网络结构：2 → 4 → 1
  1. 隐藏打分aⱼ = x₁W₁,ⱼ + x₂W₂,ⱼ + bⱼ
  2. 非线性hⱼ = tanh(aⱼ)，范围 −1 到 1
  3. 再组合z = Σⱼ hⱼvⱼ + c
  4. 转概率p = sigmoid(z)

8 个输入权重 + 4 个隐藏偏置 + 4 个输出权重 + 1 个输出偏置 = 17 个参数。这里的“一个输出”是一个分数，不是把两个类别误写成一个类别。

反向传播并不神秘：沿路把导数相乘

先拿一个只有一个权重的小例子练手：输入 x = 2，权重 w = 3，预测 z = xw = 6，目标 t = 4，损失 L = (z − t)² = 4。问：w 稍微变大时，损失会怎样变？

∂L/∂z = 2(6 − 4) = 4∂z/∂w = 2∂L/∂w = 4 × 2 = 8

步长取 0.1，w ← 3 − 0.1 × 8 = 2.2，预测变为 4.4，损失变为 0.16。这是链式法则：先问末端误差怎样变，再一路传回每个参数。

本网页网络使用交叉熵，输出分数的梯度是 p − y；回到第 j 个隐藏单元，还要乘输出权重 vⱼ，以及 tanh 的导数 1 − hⱼ²。所有四点的贡献取平均，再由 Adam 更新参数。上面手算用的是普通梯度下降与平方误差，为的是把链式法则单独看清。

03

多层不自动等于强大

拿掉弯曲

两层线性，仍然是线性

去掉 tanh 后，z = (xW₁ + b₁)W₂ + b₂，可以合并成 x(W₁W₂) + (b₁W₂ + b₂)。参数还是 17 个，分界却仍只能是直线。观察两个模型的损失，而不是只比较参数数量。

看见边界

四角学对，不等于全图学对

把查看位置移到中央或四角之外。那里没有训练标签，颜色只是模型自己延伸出的预测。这次四点小实验没有测量泛化能力，也没有证明模型“理解了开关”。

传递信号

非线性也有代价

tanh 接近 ±1 时，导数 1 − h² 很小，反向的变化就会变弱。更大初始权重、不同噪声和不同种子，都可能改变学习过程。深度不是免费的魔法。

隐藏层提供新的表示；非线性让表示能弯曲；反向传播把同一个误差分配回每个参数。

一个可以先猜再验证的小挑战
  1. 学习到 200 步，切换两个模型。先猜四角哪一格最难，再查看表格。
  2. 继续到 1200 步。线性版的四个概率会接近 0.5，损失接近 log(2) ≈ 0.6931。
  3. 恢复默认，确认两种模型的起点相同。只有隐藏层的处理不同，更新规则与四个训练点保持一致。

接近 0.5 的概率可能因浮点精度略高或略低于 0.5，所以不要把此时的微小阈值翻转误读为已经学会 XOR。这里保留概率与损失，不用这样的舍入边界制造“准确率”。

04

从四道透明的题，走到完整实验

网页真实实现了 2→4→1 的前向计算、链式法则梯度与 Adam。两个模型复制相同的初始参数，训练数据仅为这四个干净的 XOR 角点。随机初始化使用浏览器固定种子 42；它不是 NumPy 的随机流。

原 Python 同样使用 17 个参数、tanh、步长 0.03 和 1200 步，但主要实验分别生成128 个训练、128 个验证、128 个测试点，并给输入加入噪声。它另外检查精确四角、移除非线性、更大初始化，以及更强噪声下的失败点；包含数值梯度检查和参数重载验证。

网页只解释机制，表中没有独立测试成绩。若要比较原版完整实验，请实际运行源码，不要把这四个点的损失当作 Python 的测试结果。
