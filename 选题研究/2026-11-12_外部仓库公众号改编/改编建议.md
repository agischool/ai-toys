# Karpathy 仓库与 CS329Z 作业：公众号改编建议

核查日期：2026-11-12。定位：供「看得见的 AI」选题使用的编辑建议；候选篇目不等于已经制作完成。

两组资料都能改编。沿用本仓库长文的做法：从一个能观察的问题出发，用小案例解释一个机制，展示失败情形，附上来源与证据性质。阅读不要求会编程，代码留作选学。

## 先分清两组素材

X 帖列出 Karpathy 的 7 个仓库：micrograd、nn-zero-to-hero、minbpe、nanoGPT、llm.c、nanochat、autoresearch。它是一份学习资源清单，适合按机制拆选题，不能把清单本身当作一套已经验证的课程体系。

CS329Z 组织当前有两个 assignment 仓库：assignment1-harness 和 assignment2-evals。另外的课程网站、lecture5-frameworks 不是额外两份作业。两个作业都是 starter；HW1 的主要适配函数仍抛出 NotImplementedError，不能把仓库自带接口、测试要求写成完成后的实测能力。

## Karpathy：选择新问题，不按七个仓库机械写七篇

| 仓库 | 可改编的问题与小例子 | 与已有文章的关系 | 建议 |
| --- | --- | --- | --- |
| micrograd | 一次算错，责任怎样沿计算路线传回？用几个标量加乘检查梯度 | 第 04 期、Python T03 已讲反向传播 | 作为补充实验，避免重写同一篇入门 |
| nn-zero-to-hero | 从预测下一个字符，到生成一小段文字，模型怎样逐步变复杂？ | 与第 08—10 期重合较多；它本身还是课程和笔记本集合 | 用作备课和学习路线来源，不与其他仓库算作七个独立必修阶段 |
| minbpe | 同一句话，为什么会被切成不同的 token？用重复短串演示合并 | 第 08 期介绍生成单位，但仍可深入分词 | 优先：适合纸面图解和轻量实验 |
| nanoGPT | 训练时分数下降，为什么新文本未必写得更好？比较训练集与保留文本 | 承接第 02、08、21 期 | 可做微型训练观察；官方已标记旧项目并引导到 nanochat |
| llm.c | 同一套数学运算，为什么换实现后速度会变？画出数据搬运与计算路线 | 承接第 12、22 期，新增底层实现视角 | 放进阶番外；C/CUDA 和 GPU 环境门槛较高 |
| nanochat | 从会续写到会聊天，中间要接上哪些环节？拆开分词、训练、微调、评测与推理 | 可支撑第 21、24 期 | 先讲流程；完整训练另行评估资源 |
| autoresearch | AI 改了一次代码，怎样决定保留还是撤回？比较固定预算下的验证指标 | 承接第 20 期评测，增加迭代实验 | 适合后续专题；规则模拟与真实代码修改实验分开标注 |

推荐先选三个问题：「文字怎样切成 token」「会续写怎样变成会聊天」「AI 改完代码，凭什么说变好了」。这是选题优先级，不预占正式期号；第 21 期等已有策划优先合并。

原帖中的几处说法需要收窄：

- micrograd 的「约 100 行」指自动微分引擎；README 还另列约 50 行的神经网络库，不是约 100 行复现完整大模型。
- minbpe 展示字节级 BPE。文章应说「一种常见分词方法」，不沿用「每个大语言模型都从这个分词器开始」的泛化说法。
- nanoGPT 当前 README 已明确标记为旧项目并推荐 nanochat。教学上仍可阅读它的简洁实现，资源推荐应注明状态。
- nanochat 的约 48 美元是作者在特定 GPU、时长、租价和能力评测口径下的估算。README 给出的算例为 8 张 H100、约 2 小时、每 GPU 每小时约 3 美元；不代表普通电脑的完整复现报价，也不代表与 GPT-2 所有能力相同。
- autoresearch 的 5 分钟是每次训练的预算，README 明确排除启动和编译；原版要求 NVIDIA GPU，测试硬件为 H100。不能写成任何电脑都能一夜自动取得科研突破。

HW2 适合进一步扩展「给 AI 出考卷」的候选主题：说明题目、执行环境与判分规则怎样共同构成一个评测任务。README 提供 Harbor、Docker 与示例任务的入口，writeup 分为基础、运行示例、自建任务和同伴审阅。本轮不把完整作业拆成逐题答案，也不声称已完成 Harbor 实验。

## 与本仓库相同的交付标准

每期正式制作时提供正文 Markdown、内联样式排版 HTML、标题摘要、1—2 张正文图、横版和方形封面，以及网页目录入口。保持约 1,500—2,200 字的既有建议，按内容调整。

沿用当前策划：只续写「青少年 AI 科普连载」，「少年 AI 观察室」保持 16 期；Python 实验作为选学材料。建议先完成 17、18，再把 19、20 做成一个连续单元。

实验分三种标注：纸面推演、可运行的规则模拟、真实模型实验。规则模拟可以验证参数校验和停止路径，不能用来证明模型会自主选择正确工具。真实实验另记模型版本、代码提交、输入、重复次数、耗时与费用。

两份 CS329Z README 均说明 MIT 许可，HW2 LICENSE 已核对；直接复制或实质改编代码、文档时保留适用的版权与许可文本。原创文章注明参考来源；不据此推定外部邮件数据、课程视频或所有插图都适用同一许可。
